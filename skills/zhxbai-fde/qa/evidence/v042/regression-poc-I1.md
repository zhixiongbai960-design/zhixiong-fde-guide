# 当前题面 I1

我是外部F，只负责方向建议。客户说“这个资料问答POC感觉八成能用”，给了一张满意截图；测试总数、原始问题、答案来源、是否人工改过、失败项都没有。现在让我直接写值得买正式系统。请给能提交的短结论和一个最小补证据动作，不替客户做采购决定。

# 逐字答案

**可提交的短结论：**
目前仅有客户主观好评和一张满意截图，可作为继续核验的线索，不能把“八成能用”写成80%的可用率，也不足以支持“值得购买正式系统”。测试范围、原始问答、来源依据、人工介入和失败记录均待核实，现阶段既不能确认POC效果达标，也不能据此判定方案无效；约定工作是否完成需另核对。外部F建议先补一轮可追溯证据，再由客户业务与投入负责人结合正式范围、持续运行条件及成本决定是否采购。

**一个最小补证据动作：**
请客户业务负责人选一段真实资料问答工作，与实施方事先圈定一小批原始问题，做一次留痕复测。逐题并列保存原问题、资料及版本/答案出处、系统原始输出、客户采用或需重做的部分及原因，并记录人工筛选、改答、复核、重试和耗时；全部问题均登记，失败项也保留，明确总数与未覆盖条件。这批记录只用于判断该范围内继续、调整还是停止，不外推整体可用率。外部F提供记录口径与方向建议，不代替客户验收或批准采购。
