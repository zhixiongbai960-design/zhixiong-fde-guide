## 实际业务答复（原文）

# 合成物料清单补货建议：45分钟案例教学设计

**定位：合成课堂练习原型，不是真实客户项目，也没有作者实际项目成功背书。当前状态为“待骨架交付、待非原开发者预演”。** 以下是待验证的45分钟安排，不代表已经能在课堂完成，更不代表全班容量已验证。班级人数与基础差异保留待确认。

## 一、轻量案例卡

- **场景、使用者与问题：** 学员使用合成物料清单，依据已有安全库存规则生成补货建议，交由人复核。练习不接采购接口，也不执行采购。
- **已有证据：** 样例和规则说明已齐；学员已会打开工具、读样例、改一个配置值。尚无完成的工程骨架、讲师或助教预演记录。题面没有提供具体字段、规则公式和样例数值，本文不代填。
- **唯一新增复杂度：** 把规则和项目配置分开。规则表达“怎样判断和生成建议”，项目配置表达“本次运行采用哪些可配置取值”。哪些取值允许配置，以已有规则说明为准，不假定所有安全库存值都能随意调整。
- **本节核心结果：** 学员能指出规则与配置的入口；借助交付好的骨架运行已有样例、修改一个已有配置值；完成正常、缺失和一次未演示规则变化的核验；交出带人工复核标记的建议与简短测试记录。
- **排除项：** 从零开发应用、接口接入、采购执行、真实客户资料、批量工程优化及另加项目。骨架开发不是45分钟内的学生任务。
- **最小架构：** 合成输入 → 必需字段检查 → 读取独立的规则与项目配置 → 生成补货建议或待核对提示 → 人工复核。规则变更不得靠改输入或项目配置来伪装实现。
- **课堂与真实项目的差异：** 本例仅有合成输入、既有规则和人工复核，不验证真实库存数据质量、企业权限、采购系统对接或生产运行能力。这些是本例没有覆盖的事项，不是某个真实项目的既成事实。
- **材料与授权边界：** 使用已有合成样例、规则说明、交付骨架和测试记录模板，不需要真实账号或外部接口。教学材料发放前仍核对骨架、依赖和素材的使用许可；题面未提供许可状态，不视为已经确认。
- **人工责任：** 学员记录修改与核验；复核者检查建议依据和缺失信息，不把程序输出当作采购批准。讲师确认规则解释和标准结果，工程工具或相应执行者完成骨架，非原开发者负责预演反馈；主理人与相关讲师确认最终范围。具体人员待定。

## 二、45分钟建议安排

| 时段 | 教学环节 | 学员产出与范围控制 |
|---|---|---|
| 0–4分钟 | 需求 | 说清输入、建议输出、人工复核，以及“不接采购接口”。 |
| 4–7分钟 | 评审切小 | 确认只学规则与配置分离，读懂本节验收项，不扩展功能。 |
| 7–13分钟 | 方案 | 对照已有规则说明识别两类入口；讲师只演示基线和已知配置修改，不展示独立变化的解法。 |
| 13–23分钟 | 构建与按需接入 | 学员使用已准备骨架，载入现成合成样例，修改一个已有配置值并运行。只使用本练习已有输入，不安排外部接入。 |
| 23–29分钟 | 正常与缺失测试 | 对照预先核定的预期结果核验，记录缺失提示及人工处理要求。 |
| 29–37分钟 | 未演示规则变化 | 先说明改哪里及理由，再修改、运行并核验；记录收到的帮助。 |
| 37–41分钟 | 测试交接 | 交出版本、配置、结果、测试记录和待人工核对项，由另一人按说明检查。 |
| 41–45分钟 | 复盘 | 说明规则与配置的区别、变化影响、未覆盖事项及人工责任。 |

**23–45分钟的测试、独立变化、交接和复盘为保护时段。** 预演发现前段超时，应先减少讲解、操作步骤或样例数量，或由执行者完善骨架；不挤占后段，也不靠加夜课完成。上述时间是设计预算，是否可行要由实际预演验证。

## 三、骨架交接要求

由工程工具或相应执行者实现，讲师验收教学适配；这里提供交接规格，不编写业务代码。

1. **可直接开始练习。** 在预演所用工具和环境中，按一页操作说明即可打开、载入样例、运行并查看结果。记录准备条件和操作步骤，不能把未完成的环境配置藏到课堂时间之外。
2. **规则与配置入口清晰且分离。** 指明各入口的位置、用途、允许改动的范围，以及修改后如何运行、恢复基线。选择适合现有学员基础的编辑方式，不临时增加编程语言或框架教学。
3. **规则忠实。** 讲师将已有说明对应到骨架中的规则和配置，确认字段含义、单位、比较边界、补货数量计算和例外处理。说明没有给出的内容列为待定，不能由工具自行编造。
4. **异常行为可见。** 至少支持本节指定的一个必需字段缺失情形。建议课堂处理为：明确指出缺失项，将该记录标为待人工核对，不把缺失值静默当作0，也不输出该记录的确定补货数量。此为待讲师确认的教学处理约定；与已有材料冲突时先修订并统一预期。
5. **结果可核对。** 能把输出对应回输入记录，查看所用规则和配置版本；建议结果、异常提示与待人工复核状态可区分。具体展示形式从简，不要求另做界面。
6. **交付两套材料。** 学员包包括基线骨架、已有说明、样例、操作指引和空白测试记录；讲师包另含预期结果、缺失处理约定、独立变化任务及其核验答案。独立变化答案在完成前不发给学员或预演者。
7. **独立变化可在单处完成。** 执行者预先确认该任务只需要修改一个规则入口，无须增加字段、接口或新项目；但不能把修改后的成品提前给学员。

建议复用的教学方法规格为：输入“既有规则说明、合成样例、已验证骨架”，输出“规则/配置位置说明、修改记录、核验结果、人工交接说明”；缺少必需数据时保留待核对状态，不替人批准建议。复用的是教学和核验方法，不把本例包装成已开发完成的业务Skill。

## 四、三类任务及核验要求

### 1. 正常任务

从已有样例中选一条字段齐全、预期结果能依据现有规则明确核对的记录。若样例覆盖会生成建议和不会生成建议的情况，可各选一条，但不为凑覆盖编造数据事实。

- 学员先从规则说明写出预期，再运行并比对。
- 修改一个已有项目配置值后再次核验，指出配置改变了什么、规则本身是否保持不变。
- 记录输入标识、配置前后值、规则版本、预期、实际和差异。具体数值由讲师从现有材料选定。

### 2. 缺失任务

复制同一条已有合成样例，删除一个由现有规则明确要求的字段，保留基线输入不动。该字段由讲师指定，不临时引入新的业务字段。

- 先预测会出现什么提示、哪条记录不能形成确定建议，再运行核对。
- 核验骨架是否按已确认约定标识缺失，是否错误地产生了确定数量。
- 交接时说明缺什么、由谁补充或核对。其他完整记录继续计算还是整批停止，由讲师依据已有材料确定并写入预期，不能含糊处理。

### 3. 未演示规则变化任务

**教师准备卡，具体内容待已有规则映射后填写：**

- 原规则条款：〔引用现有说明中的一条判断规则〕。
- 新规则条款：〔讲师确认的、仅改一个判断条件或比较边界的课堂变化〕。
- 固定项：输入字段、项目配置和输出范围均不变。
- 核验数据：从已有样例选择能区分新旧规则结果的记录，并保留一条不受影响的记录做回归核验。若现有样例不能区分两者，先调整所选变化，不假定材料已经足够。

这是一项待讲师确认的合成练习变化，不是对原业务规则的事实补充。题面没有给出实际条款，因此现在不能写死新公式或数值。

任务在29分钟时才揭示。学员必须先写“改规则还是配置、具体位置、预计哪些结果改变”，再修改、运行并解释。只改一个配置值不算完成规则变化任务；直接复制已改好的骨架也不能作为独立迁移证据。

记录是否使用提示、获得定位帮助、看到参考答案或直接采用成品，并保留初次判断。若需要额外开发才能支持该变化，应在课前缩小或更换变化，不占用测试时间临时造功能。

## 五、非原开发者预演与记录

**预演者须未参与骨架开发，使用实际计划发给学员的工具、材料和操作说明。** 优先选择符合题面已有能力的人员；若预演者能力明显更强，记录这一差异，不能据此推断初学者也能完成。讲师和助教尚未预演，现阶段不填写成功结果。

每次记录至少包括：

| 记录项 | 应记内容 |
|---|---|
| 条件 | 日期、预演者及其基础、是否原开发者、工具/环境、骨架和材料版本。 |
| 配置准备 | 开始前为环境、样例载入和配置做了什么，耗时多少；区分课前准备与课堂操作。 |
| 分段实耗 | 讲解、练习操作、正常测试、缺失测试、独立变化、交接、复盘的实际起止时间；另记阻塞等待和帮助时间，避免重复计时。 |
| 阻塞与帮助 | 卡在哪一步、原因、谁提供什么帮助、是否需要改骨架或说明、恢复用了多久。 |
| 核验证据 | 输入及版本、修改位置、预期与实际结果、差异、输出或必要截图。只记录实际观察到的结果。 |
| 独立性 | 变化揭示时间、运行前判断、提示次数与内容、参考答案或成品的使用情况。 |
| 交接与复盘 | 另一人能否按说明核对，人工责任是否清楚，哪些问题仍未解决。 |
| 修订与复测 | 实际总耗时、是否保住各保护时段、需缩小或修订的内容、负责人及复测安排。 |

预演可支持的结论仅限该预演者、版本、工具和任务条件。若超时或独立变化依赖答案，记录事实并修订后再测，不用“最终跑出来了”代替教学有效性证据。

## 六、共创待决项与开课前检查

- **工程执行者：** 完成骨架并交付上述材料，确认本节操作不依赖额外开发。
- **主讲者：** 从已有材料选定具体配置项、缺失字段、新旧规则条款和预期结果；修订材料并核对许可。
- **非原开发者：** 完成45分钟限时预演，返回实耗、阻塞、帮助与独立变化证据。
- **主理人与相关讲师：** 根据预演决定继续、缩小或修订范围，确认班级人数、基础分布及助教响应安排。支持标准由实际资源决定，不预设人数比或准入分数。

在骨架和预演证据齐备前，只能把本方案作为待验证的教学设计。若无法按时补齐，教学团队需另行决定缩小范围或改为材料分析练习，不能将其宣称为已完成的45分钟动手课程。
