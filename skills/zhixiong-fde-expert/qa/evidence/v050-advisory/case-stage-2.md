## 一、准备分工与交付顺序

### 1. 讲师：先冻结教学与规则口径

交给工程工具一份短规格，至少写清：

- 本例是合成课堂原型，没有真实项目成功背书，不接采购接口，输出必须由人复核。
- 唯一新增知识是“规则与项目配置分开”。标明现有规则中哪些属于判断逻辑、哪些允许配置，选定课堂要修改的一个配置项。
- 从已有样例中选定正常输入，写出依据现有规则得到的预期结果，不由工程工具猜公式或业务含义。
- 指定一个必需字段缺失的异常输入，确认提示内容、该记录是否停止出建议、其他记录是否继续处理，以及人工核对责任。上一答的缺失处理建议须经此确认后成为测试依据。
- 选定一项真正改变规则、而不是只改参数的独立变化。只改一个条件或边界，不引入新字段、接口或额外项目；确定能区分新旧规则的已有样例和一条回归样例。
- 独立变化任务与答案放在讲师材料中，预演和课堂到指定环节才揭示任务；答案在学员完成前不发放。

具体字段、公式、新旧条款和数值仍应取自已有材料或由讲师明确确认，目前不能代填为既有事实。

### 2. 工程工具／工程执行者：完成可教学的最小骨架

根据讲师冻结的口径实现并交付：

- **分离的入口：** 规则和项目配置位置清楚，可分别定位、修改、运行和恢复基线。不要让初学者为改一个条件而遍历整个工程。
- **最小处理链：** 读取合成清单 → 校验必需字段 → 使用规则与配置生成建议或待核对提示 → 展示人工复核信息。不增加采购接入。
- **可核验的输出：** 输出可对应回输入记录，能够识别规则和配置版本，正常建议与异常提示可区分。
- **基线验证材料：** 正常与缺失样例、预期和实际结果、已知问题及适用环境。工程自测是交付证据，不替代非原开发者预演。
- **学员交接包：** 已准备好的骨架、现成样例、操作指引、修改入口说明、恢复方法和空白测试记录。环境准备步骤与耗时单列，不隐藏为学员已经掌握的能力。
- **讲师交接包：** 规则与配置映射、标准结果、独立变化及其核验依据。确认该变化能在一个清晰规则入口内完成，不要求临场补开发。

本节的“构建”是学员操作和修改已交付骨架，不是课堂内从零开发业务Skill。

### 3. 讲师验收材料，非原开发者实际预演

讲师先核对骨架是否忠实表达规则、说明能否指导操作、预期结果是否一致，再交给未参与开发的人限时走完整流程。

那位看过演示的助教可以实际预演，但必须记录“看过哪些演示、是否见过变化答案、得到哪些帮助”。不能把看演示的时间和感受补写成操作成功记录。若其已经见过独立变化的答案，应另选未展示过的同等复杂度变化。

### 4. 主理人与相关讲师：做最终范围及组织判断

结合实际预演记录决定修订、缩小或安排开课。班级人数、基础差异、工具可用性和助教响应负荷仍待核对，不预填人数，不给无依据的师生比或统一准入分数。

## 二、45分钟时间边界保持不变

| 时段 | 内容 |
|---|---|
| 0–4分钟 | 需求、合成材料定位、人工复核边界 |
| 4–7分钟 | 评审切小与验收项 |
| 7–13分钟 | 规则与配置分离的方案讲解 |
| 13–23分钟 | 操作骨架、载入已有样例、修改配置；无外部接口接入 |
| 23–29分钟 | 正常与缺失异常测试 |
| 29–37分钟 | 未演示规则变化：先判断修改位置，再操作与核验 |
| 37–41分钟 | 测试交接 |
| 41–45分钟 | 复盘 |

这是待预演验证的时间预算。**23分钟后的测试、独立变化、交接和复盘不能被前段挤掉。** 若骨架准备不充分，优先补齐骨架、缩短操作路径或减少讲解和样例数量；不靠删测试、给成品答案或追加课时“达标”。

## 三、建议的最小预演门槛

以下是供教学团队确认的最低证据要求，不是代主理人宣布的正式准入标准：

1. **用实际交付物。** 骨架完成且版本固定，预演使用将发给学员的工具、材料和操作说明。准备工作与课堂工作分开计时，前置条件可供课堂实际落实。
2. **由非原开发者动手。** 记录其基础与目标学员的差异。至少取得一次完整实际预演记录，才能讨论这套材料在该条件下是否可行；这仍不足以证明全班都能完成。
3. **完整计时。** 记录配置、讲解、练习、正常测试、缺失测试、独立变化、交接和复盘的实际耗时，同时记录阻塞、等待与帮助。验证是否在45分钟内完成全部环节，不能只统计程序运行时间。
4. **正常和异常都有证据。** 对照讲师确认的预期，保存输入、规则与配置版本、实际输出和差异；缺失数据不能被无提示地当作正常数据产生确定建议。
5. **独立变化有运行前判断。** 预演者先说明改规则还是配置、改哪里、预期哪些结果改变，再修改和核验。记录提示和参考成品使用情况；在帮助下做完如实记为“得到何种帮助后完成”，不记为独立迁移已验证。
6. **交接与复盘没有省略。** 接收者能按说明核对结果并找到待人工处理项；预演者能解释规则与配置的区别、此次变化的影响和未覆盖范围。
7. **失败与修订可追踪。** 记录超时点、错误、材料歧义、工程阻塞、修订负责人和复测版本。修订后重新验证受影响环节及整段45分钟流程，保留前次事实，不改写成一次成功。

最简记录格式可用：

“预演者与基础｜已看过的材料｜工具及版本｜各环节起止时间｜预期与实际｜卡点与帮助｜独立变化的事前判断及核验｜交接问题｜修订与复测安排”。
