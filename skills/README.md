# 志雄 FDE Skills

志亚科技出品 · 作者：白志雄。

## 推荐：学员只安装一个总技能

[zhxbai-fde](zhxbai-fde/SKILL.md) 覆盖从客户机会、需求、POC、范围报价与合同，到架构构建、交付接管、回款维护和复盘的项目全流程。内置《志雄 FDE 实战指南》33篇完整文字、按需资料索引与可执行方法，不依赖另装需求技能或8个垂直技能。

用户可以直接问“现在项目卡在哪一步”“用第22篇帮我处理POC标准”“根据已确认范围生成MVP规格”。总技能按当前问题选资料，不会每次读33篇或强推一套阶段流程。

正文资料可离线定位；图卡和GitHub页面需要联网。包内版本固定于已记录提交；询问最新时核对远程，没有联网就明确说明，不能宣称自动保持最新。

导入或安装时选择完整的 zhxbai-fde 目录，包含 SKILL.md、references 和 LICENSE，不能只复制入口文件。按宿主支持的本地目录/仓库子目录方式安装；本次仓库发布不等于已在任何宿主安装。本轮不要求WorkBuddy安装验证。

## 按环节单独使用

熟悉工作流、只需要某一环节时可选择以下独立技能；若已安装总技能，不需要重复安装：

- [zhxbai-fde-ready](zhxbai-fde-ready/SKILL.md)：课前就绪。
- [zhxbai-fde-knowledge](zhxbai-fde-knowledge/SKILL.md)：项目知识整理。
- [zhxbai-fde-review](zhxbai-fde-review/SKILL.md)：需求判断。
- [zhxbai-fde-scope](zhxbai-fde-scope/SKILL.md)：机会、范围与变更。
- [zhxbai-fde-design](zhxbai-fde-design/SKILL.md)：最小方案。
- [zhxbai-fde-build](zhxbai-fde-build/SKILL.md)：业务Skill构建。
- [zhxbai-fde-deliver](zhxbai-fde-deliver/SKILL.md)：验证交付与复盘。
- [zhxbai-fde-case](zhxbai-fde-case/SKILL.md)：讲师案例设计。

既有 fde-* 地址保留兼容，旧链接和安装目录不删除。新安装推荐 zhxbai-fde-* 名称，不要同时安装同一垂直技能的新旧版本以免重复触发。原 requirement-analysis 仓库仍保留；总技能已携带其需求追问和MVP规格方法，并保留来源/许可说明。
