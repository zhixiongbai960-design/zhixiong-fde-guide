# 志雄 FDE 实战指南

**志亚科技出品 · 作者：白志雄**

从真实业务需求出发，讨论企业 AI 项目如何判断、构建、交付和复盘。内容覆盖客户沟通、需求边界、确定性架构、权限与数据、稳定性验证、交接验收和项目经营。

本指南由 **武汉市志亚科技有限公司** 整理发布，面向企业 AI 落地实践者、独立开发者和希望理解 FDE 交付方法的学习者。

**33 篇文章 · 40 张封面 · 89 张图解**。文章保留完整正文，配套图卡可直接查看与下载。文中经验与示例用于理解方法，不代表对特定项目效果的承诺。

> 个人非商业学习和使用免费；企业业务应用、客户交付、付费培训及其他商业用途须事先取得书面授权。
