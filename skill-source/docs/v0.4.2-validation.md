# 0.4.2 行为修复与可选决策资料

基线：GitHub提交 `9875a8b1750aafb7dbc1c96f63b12a4b1bdd98e9`，版本0.4.1。日期：2026-11-09。本记录说明实际修改、验证及限制，远端发布以对应GitHub提交为准。

## 本次修改

- 项目切换只复用方法，不继承别的项目的业务对象、字段、记录归属、授权、证据或阻塞；切回时保留原项目仍有效的记录。
- 报价正文紧邻标明“已约定”“报价拟含、待确认”和排除项；后续确认后更新状态。估算不自动成为客户承诺。
- 简单问题先给短而充分的回答，按请求展开详细方案。“不足以判断”是有效结果，同时说明能确定的部分、关键缺口和最小查证，不阻断不依赖缺口的已授权低风险准备。
- 评审说明具备或不具备哪些条件，不由AI冒充组织批准人；仍可按有权用户已作出的决定起草供审核文字。
- 总角色以作者公开方法及本人确认的表达为蓝本，直接、实在、贴近现场；仍是AI而非作者本人，不虚构经历、性格或作者背书。
- 既有决策资料是可选输入。只读用户指定、获准使用的索引和相关正文，保留来源、确认状态及具体结论的替代范围。缺库、缺权限、信息冲突时说明限制，不声称已接通真实公司库。
- 新经验先形成待确认修订。作者确认、项目操作授权和公开发布授权分别核对；内部事实、私有配置与公开方法分开，不能自动同步、发布或更新已安装包。

权威源只改四份方法（progress、commercial、knowledge、operate）及总入口；注册表更新对应版本。受影响独立包为knowledge、next、deal、poc、run、code，均为0.4.2；其余12包逐字节保持0.4.1。依赖图、构建器、33篇指南正文、4份许可及模板均未改动。独立方法不新增人物身份依赖。

## 实际验证

- **41个最终版实际模型响应**：六个受影响独立包20轮，总包21轮，分别独立审阅，均通过本轮明确断言。详见[完整回归报告](../qa/evidence/v042/regression-report.md)、[逐项结果](../qa/evidence/v042/case-results.json)及各轮原题/逐字响应。
- 另有旧0.4.1基线4轮、中间候选总包2轮，未混入最终通过数。每组初次是新会话，后轮保留该组历史；总包分主链15轮和身份/知识/修订链6轮。
- 37项标准库包装测试通过；19个Skill入口元数据校验通过；293个运行资料Markdown相对目标均存在。未把这些结构检查计作行为测试。
- 旧QA被原门禁拒绝。取得六包各至少两轮真实响应及独立审阅后才更新QA指纹、构建总包；没有修改构建器或绕过门禁。
- 模块与总包verify通过。发布目录按构建输出同步，独立包清单331文件，总包清单128文件；6包涉及的9份方法与总包逐字相同。总包64个运行文件与最终受测预览零差异。
- 合成知识原件另存 `qa/fixtures/fde-v042/`，相关证据附逐字原件及SHA256，使总包离线证据仍可复核。公开记录仅规范显示路径，没有修改业务题面或答案。

## 对照与限制

旧0.4.1在本次四轮定向序列中也通过，未复现原长、多包混合上下文中的残留问题。因此本次结果支持有针对性的规则澄清与当前场景通过，**不证明因果修复或永不串项目**，也不能将问题归因为已证实的宿主缺陷。

短答测试中，独立deal为896字符、总包561字符，达到执行前设定的1000字符可读性目标，但不称极短。要求详细时能展开。总包部分知识题按用户限制仅读指定材料，工程题沿用先前方法；不宣称每条自动路由都首次触发过。

所有测试资料均为合成，未接真实公司决策库，未做目标宿主安装、真实业务接口、客户验收、部署或跨模型重复测试。宿主的身份、安全及工具约束始终存在，没有无Skill对照，不能把全部表现归因于Skill文本。通过数不是成功概率，未改的12包沿用历史证据而非本轮重测。

公开发布不改变原许可，不代表已安装或真实项目可上线。私有决策资料接入仍需在用户授权的实际环境中单独配置与验证；本次只提供方法协议，没有自动连接、扫描、写回或同步实现。
