# 项目与课堂能力覆盖

版本0.5.0。每项方法源于白志雄《志雄FDE实战指南》完整正文或用户已形成的课程方法，不复制第三方参考包的文本、阶段编号、知识卡或脚本。

0.5.0 是当前参谋版本，公开发布以对应仓库提交为准。方法负责具体分析、产品/架构/接口/权限设计、工程交接与证据评审，不直接或委派承担业务实现，不代最终决定。课程仍可包含编码与运行，由学员、讲师及专门编程工具完成，不能把课程产出都算成本技能实现。18 独立包已按精确受测字节同步；旧总包和8旧入口保留旧职责，不代表本版。模块验证、专家回归、发布与宿主安装须分别核对。

## 课堂方法在一个总技能里怎样用

| 课堂方法或问题 | 总包处理 | 学员可得到 |
|---|---|---|
| 真实任务走查、As-is/To-be、目标/问题/卡点/依据 | requirements | 逐轮一问及一页需求，不靠背公式 |
| 场景/问题/目的是否说清，能否下一步 | review + scope | 明确下一阶段、理由、缺口、可做子范围及下一问 |
| MVP切小、输入处理输出与使用 | requirements + design | 本人确认范围后的规格和最小流程 |
| MVP产品设计文档是否OK | product-review | 原文位置、影响、具体修订与可开工/阻塞结论 |
| Agent/Skill/API/数据/人工分工 | design + engineering | 按需要选组件，不强凑三套系统 |
| 知识与来源、上下文选择 | knowledge + design | 最小索引、所需材料、事实/推断/未知 |
| 方法与配置分离、业务Skill封装 | build | 可实现的方法规格、配置边界、样例预期与工程交接 |
| 首跑、换输入、异常停止、重启与同伴试用 | engineering + deliver + operate | 有版本的实测/未测记录和交接说明 |
| 课程实操前环境四步 | ready | 实际就绪/自述/未做及辅导项 |
| 按实际课表开展真实案例、独立变化、预演 | case | 教学版范围、真实/简化差异、预演及迁移 |
| 按实际课表安排路演与复盘 | deliver + operate | 有证据的项目叙事和下轮验证 |
| 客户沟通/谈判/报价/合同/回款/维护 | chat + engage + commercial + operate | 基于原话的判断、待确认项、具体草稿与责任边界 |

正式专家包发布后，学生只安装zhixiong-fde-expert即可按对话调用这些包内方法。指定单独垂直技能不是前置条件。课堂问概念可以直接讲解，当前项目已有清楚输入则直接评审/产出，不强迫重走访谈。

## 能力边界

评审设计可开工不等于实施已成功，AI判断不代替有权者确认，客户真实心理不可直接观察，法律/财税/行业安全与具体系统约束需专业资料或人员核对。33篇提供方法判断依据，不保证覆盖每个行业或解决一切现实问题。


## 独立模块与总包

独立入口与方法的对应以[src/registry.json](../src/registry.json)为准。18个独立包均从[src/methods](../src/methods/)生成，携带所需原文与模板，无须另装其他模块；总包在逐模块测试和独立评审通过后组装。总包只是固定快照，不自动追随源码变化。七天3+3+1是可选课表示例，不是技能前置，也不表示合作方已确认。
