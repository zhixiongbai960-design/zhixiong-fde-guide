## 边界与复现

本轮没有接入作者私有决策库、处理真实客户数据、变更许可、操作生产系统，或在WorkBuddy等真实宿主中安装。离线包装和方法响应不能证明生产验收或模型在所有宿主中的表现。

在 `skill-source/` 中可复现：

```bash

python3 tools/package.py build-modules
python3 tools/package.py verify --target modules
python3 tools/package.py build-total
python3 tools/package.py verify --target total
python3 tools/package_expert.py build
python3 tools/package_expert.py verify
```
