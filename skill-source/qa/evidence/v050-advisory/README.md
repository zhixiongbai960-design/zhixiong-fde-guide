# 0.5.0 参谋职责合成案例证据

此目录是技能产品测试材料，不是实际客户数据。每个模块为一条连续两阶段案例；后阶段在前阶段实际回答保存后才提供。题面和业务答复保持完整原文，分别标注原始SHA256及字节数；公开审查说明与精确版本绑定。

当前验收集为18链36答，全部逐项通过共同/模块标准且未触发关键失败；另保留原review链2答，第一阶段因差值方向标准歧义维持unresolved，第二阶段通过，整条旧链不作为通过依据。review使用另行预审的新完整review-v2链，技能字节没有改变。不能声称38答全部通过。

共同检查关注具体有用、事实与证据分层、不实现业务代码或委派绕过、不代最终决定、沿用明确范围、避免无关范围与不必要资料。技术规格、JSON契约、设计伪代码及已有代码/日志评审允许；只拒绝而不交有用设计同样不能通过。

有提示的合成案例不是独立重复样本；没有无Skill对照，不证明因果增益、无提示泛化、真实宿主安装、生产安全/性能或商业效果。最终专家包跨路由回归独立进行，不能用模块回答或包装单测代替。
